# Signalement de sécurité

Utilisez le signalement privé GitHub de ce dépôt lorsqu'il est disponible. À défaut, demandez au mainteneur un canal privé avant de transmettre les détails. Dans les échanges, utilisez des données fictives et retirez les jetons, coordonnées, noms d'élèves et copies de journaux contenant des données personnelles.

Précisez la version concernée, le périmètre et les conséquences observées. Si des données d'une école sont concernées, avertissez également son responsable du traitement ou son DPO via son canal d'incident.
